# Environment

Public client variables: `VITE_API_URL`, `VITE_REALTIME_URL`, and `VITE_APP_ENV`. Railway-only variables: `DATABASE_URL`, `TELEGRAM_BOT_TOKEN`, `SESSION_SECRET`, `JWT_SECRET`, `FRONTEND_ORIGINS`, `TELEGRAM_INITDATA_MAX_AGE_SECONDS`, and `PORT`. Copy `.env.example`; never commit `.env` or real credentials.
